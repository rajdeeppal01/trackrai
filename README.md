# TrackrAI

AI-powered Job Application Tracker with Gmail integration.

## Features

Track applications

Timeline of interviews/OAs/offers

Google Login

Gmail auto-sync

AI email classification

Analytics dashboard

Calendar reminders

## Tech Stack

Frontend: React + TypeScript + Tailwind

Backend: FastAPI

Database: PostgreSQL

Auth: Google OAuth

AI: Gemini/OpenAI

Email: Gmail API

backend/ # FastAPI server
